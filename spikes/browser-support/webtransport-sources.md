## Disagreements between sources

1. **Chrome "current" version.** BCD says 155 is current and 156 is beta. The Chrome version-history API shows 155.0.8059.40 at fraction 1 and also lists 156.0.8078.12 on the stable channel at fraction 0.005 since 2026-10-07. The task statement says Chromium 156 was measured; a test Chromium build can be ahead of stable.
2. **Firefox Nightly number.** BCD lists 159 as nightly and 158 as beta (release 2026-10-13). product-details lists Nightly 160.0a1 and beta 158.0b5, with `LAST_MERGE_DATE` 2026-10-08. BCD is behind by one merge.
3. **Firefox 157 release date.** BCD: 2026-09-29 for 157. product-details: `LAST_RELEASE_DATE` 2026-10-09, which is the 157.0.1 point release.
4. **caniuse versus Apple for Safari versions.** caniuse lists Safari and iOS Safari 27.1 and 27.2 as versions. Apple's release-note index has "Safari 27 Release Notes" and "Safari 27.2 Beta Release Notes"; the 27.1 page returns 404.
5. **Application protocol negotiation in Chrome.** BCD says 143; the Chrome 143 release notes describe it; the runtime flag is `stable`; the chromestatus stage has `desktop_first: 143`. The same chromestatus entry reports its status text as "Proposed".
6. **Safari column on chromestatus.** The main WebTransport entry and the serverCertificateHashes entry still say Safari "No signal" (entries last updated 2025-08). Apple's release notes say WebTransport shipped in Safari 26.4.
7. **`datagrams` on iOS.** BCD and caniuse mark iOS Safari 26.4+ as fully supported. WebKit bug 322201 (NEW) reports `wt.datagrams` undefined on iOS 26.6. The 26.4 blog post describes datagrams as part of the API.
8. **WebTransportError constructor.** Spec: `(optional DOMString message, optional WebTransportErrorOptions options)`. Chromium and Firefox: `(optional WebTransportErrorInit init)`. WebKit: two overloads. MDN documents the Chromium/Firefox form. WPT was written for the old form (issue #715).
9. **`streamErrorCode` width.** Spec and WebKit: 32-bit. Chromium: constructor input 8-bit, attribute 32-bit. Firefox: 8-bit for both. MDN says "A number in the range 0-255".
10. **RSA keys with `serverCertificateHashes`.** Spec, MDN and Firefox reject RSA. QUICHE main still returns true for RSA with a TODO to change it. WebKit's check function has no key-type test.
11. **Draft version.** The latest IETF draft referred to in Firefox bugs is draft-15. Chromium main offers draft-02 by default and draft-07 behind a disabled feature. neqo's `settings.rs` carries only the draft-02 setting codepoint.
12. **Safari 26.4 availability.** The release note lists macOS Sequoia and Sonoma for Safari 26.4. WebKit main enables WebTransport only when built for or running on OS 26 or later. No source read says whether Safari on Sequoia has the API.
