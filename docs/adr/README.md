# Architecture Decision Records

One file per decision: `NNNN-<kebab-case-title>.md`, numbered from `0001`.

Write an ADR when an item in [open questions](../open-questions.md) is decided, or when a library, protocol draft revision or component boundary is chosen. In the same change, remove the item from open questions and update its status in [requirements](../requirements.md).

Each ADR records context, alternatives considered, the decision, consequences and evidence. Evidence links to a record in [experiments](../experiments/README.md) or to a primary source with the date it was read. A decision without evidence is marked `Proposed`, not `Accepted`.

Accepted ADRs are not rewritten. A later change is a new ADR that supersedes the old one.
